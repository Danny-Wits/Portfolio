## ✨ Features

- **Smooth Scroll Animation** - Locomotive Scroll integration for fluid page navigation
- **Responsive Design** - Fully responsive layout that works on all devices
- **Modern UI** - Clean and contemporary design with smooth transitions
- **Interactive Elements** - Engaging components and hover effects
- **Fast Loading** - Optimized assets for quick page load times
- **SEO Friendly** - Properly structured HTML with meta tags

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Advanced styling with animations and flexbox/grid
- **JavaScript (Vanilla)** - Interactive features and DOM manipulation
- **Locomotive Scroll** - Smooth scrolling library for enhanced UX
- **Custom Domain** - Configured with CNAME for custom domain hosting

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/Danny-Wits/Portfolio.git
cd Portfolio
```

2. No additional dependencies needed - just open `index.html` in your browser!

Alternatively, if you have a local server:
```bash
python -m http.server 8000
# or with Node.js
npx http-server
```

Then visit `http://localhost:8000` in your browser.

## 🚀 Usage

1. Open the project in your browser
2. Navigate through sections using the smooth scroll animation
3. Interact with portfolio items and projects
4. View contact information and social links

### Customizing Your Portfolio

- **Content**: Edit `index.html` to add your projects, skills, and information
- **Styling**: Modify `structure.css` and `component.css` for custom colors and layout
- **Scripts**: Update `script.js` for additional interactive features
- **Domain**: Update the CNAME file with your custom domain
